## 第 9 题：导数重根不能充当极值点

题设对象：`f(x)=x²+ax+ln x`，定义域为正半轴。合法操作：改变 a，或选择两个极值、临界重根、无极值的预设。观察量：导数分子 `q(x)=2x²+ax+1` 的正根及符号，联动原函数上的极值点。

精确结论为 `a<−2√2`。分子有两个不同正根当且仅当判别式 `a²−8>0`、根和 `−a/2>0`，根积固定为 `1/2>0`。此时导数依次正、负、正。临界 `a=−2√2` 时，分子为 `2(x−1/√2)²`，两侧不变号；原函数在驻点处仍保持递增，不存在极值。

构造顺序：原函数与定义域 → 与导数同号的二次式 → 正根 → 正负区间 → 原函数上的极大、极小或非极值驻点。图区仅为有限观察窗口，全域判断由解析符号分析给出。

## 第 11 题：相等的是展开圆心角

左图为两个圆台的轴截面，右图为同心对齐、按相同比例缩小的两个扇环展开图。共同半径的位置可连续改变，红色径向宽度始终对应两部分母线。

上部分底面半径为 15、13，高为 8，所以母线 `l₁=√(8²+2²)=2√17`。展开弧长之差给出 `αl₁=2π(15−13)`，故共同角 `α=2π/√17`。下部分半径差为 3，因此 `αl₂=6π`，得到 `l₂=3√17`，总和为 `5√17 cm`。

上扇环实际外、内半径为 `15√17`、`13√17`；下扇环为 `12√17`、`9√17`。绘图将两者同时除以 √17 以便共同排布，这属于统一显示比例，不能将这些显示坐标误认成原圆台底面半径。下圆台高度按同一模型为 `√((3√17)²−3²)=12`，用于画合法轴截面。

构造顺序：由直径得到轴截面 → 上母线直角三角形 → 上扇环与弧长关系 → 下扇环与共同角 → 比较两条径向宽度并求和。

## 第 12 题：覆盖的是补集，复合有先后顺序

全部函数是 A 上的六个置换，以 `(f(1),f(2),f(3))` 表示。可勾选集合 C，复合表只启用行、列均来自 C 的格子。行是外层函数 f，列是内层函数 g，图中先走蓝色 g，再走红色 f。未覆盖的补集元素明确列出；空集不满足非空要求，也不画非法复合路线。

精确最小值为 2。取 `s₁₂=(2,1,3)`、`r=(2,3,1)`，则：

- `s₁₂∘s₁₂=e=(1,2,3)`；
- `r∘r=r²=(3,1,2)`；
- `s₁₂∘r=s₂₃=(1,3,2)`；
- `r∘s₁₂=s₁₃=(3,2,1)`。

这四个结果恰覆盖补集。一个函数只能产生一个平方，不能覆盖五个补集元素，所以 1 不可能。条件没有要求 C 中的函数也必须被复合覆盖。

构造顺序：六个置换 → C 与补集分区 → 三列复合映射 → 全部有序复合表及漏项 → 图内最小值与最小性论证。

## 第 16 题：交换指标把全称条件转成共线

原数列可选择等差或等比；图中均值由逐项累加后除以项数得到。可选三个不同指标并交换 i、j。为使小三角形可读，均值图显示到当前最大指标之后一项，最多九项；这不缩小数学上的全称范围。

令原轮换式为 F(i,j,k)。交换 i、j 得 `F(j,i,k)=−F(i,j,k)`，而题设要求两者均为同一常数 c，因此 `c=0`。通常坐标顺序 `(n,tₙ)` 的三阶行列式等于 `−F`，所以普通三角形面积为 `|F|/2`，不混淆符号。

固定 i=1、j=2，任取 k=n，可得 `tₙ=(2−n)t₁+(n−1)t₂=αn+β`。因此 `Sₙ=αn²+βn`，`aₙ=α(2n−1)+β`，对 n=1 也成立。轮换均值数列恰为等差数列，命题①真。

若同时是等比数列，则 `a₃−2a₂+a₁=a₁(q−1)²=0`。按高中定义首项及各项非零，故只能 q=1，命题②假，答案 A。等比模式拒绝零首项，不把零数列作为反例。

构造顺序：均值点 → 三点三角形 → 交换指标与有向量 → 前两点确定的直线 → 原数列项图与命题判断。

## 第 18 题：两问条件隔离，投影允许落在三角形外

按相似缩放令 `BC=CD=1`，使用坐标 `D=(0,0,0)`、`A=(2,0,0)`、`C=(0,1,0)`、`B=(1,1,0)`、`E=(1,0,0)`。公共条件 PA 垂直 AB 与 CD 的方向，故垂直底面；取 `P=(2,0,h)`，h>0。P 在底面另一侧的构型可由反射得到，不改变平行及夹角结论。

第一问保留自由高度。EBCD 为矩形，所以 `BE∥CD`。平面 PBE 与底面交于 BE，CD 与 BE 平行且不重合，因而 CD 在目标平面外，得到线面平行。第二问的 45° 条件不用于第一问。

第二问的二面角截面为 ∠PDA，由 45° 得 h=2。平面 PCE 方程为 `2x+2y−z−2=0`，法向量可取 `(2,2,−1)`；PA 的单位方向为 `(0,0,1)`，所以线面角正弦为 1/3。

A 到目标平面的垂足 `H=(14/9,−4/9,2/9)` 满足平面方程，`AH=2/3`、`AP=2`。H 位于三角形 PCE 之外，图中补出平面延伸，而不伪造垂足位置。PH 为 PA 的投影，所求角即 ∠APH。第二问采用更易分辨 PA、PH 的默认视角。

第一问构造：底面 → 中点 E → 顶点及侧棱 → BE → 目标平面。第二问构造：底面 → 45° 截面与顶点 → 平面 PCE → 垂足及延伸 → 投影线、角与正弦。未出现的面不会进入 Space 遮挡场景。旋转只改变相机，销毁模块时清理 Space。
