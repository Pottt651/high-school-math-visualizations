例题｜tan θ = −√3，求三角形内角 θ

① 主值：arctan(−√3) = −π/3，是负角，不在 (0, π) 内。

② 负值加 π：θ = π + arctan(−√3) = 2π/3 = 120°。

③ 检查：120° 是钝角，且 tan(2π/3) = −√3。

记住这两句

先求正的参考角，
再看锐钝选内角。

锐角直接取θ = α
钝角 π 减它θ = π − α

前提：θ 是三角形内角，α 是锐角参考角（0 < α < π/2）。原题符号不能丢；直角单独算。

例题｜为什么不能直接写 arcsin？

已知 θ 是钝角，且 sin θ = 1/2，求 θ。

  1. 先求参考角α = arcsin(1/2) = π/6，这是 30° 的锐角。
  2. 钝角 π 减它θ = π − α = 5π/6 = 150°。
  3. 代回检查sin(5π/6) = 1/2，且 150° 是钝角。

不能直接取 π/6：正弦值虽然对了，却不满足“钝角”。

不是因为 arcsin(1/2) 为负——它是正的！原因是 arcsin 的主值范围为 [−π/2, π/2]，不会直接给出钝角。若去掉“钝角”条件，内角有 π/6、5π/6 两个解。

为什么必须限制角的范围？

一个输入只能对应一个输出，才能称为函数。这个规定范围内的唯一角，叫作主值。

反函数不是倒数，复合也有范围条件

arcsin x ≠ 1/sin x。“arc”表示取反三角函数，不表示倒数。

拖动图中蓝点或滑块，观察输出角。

一般解与端点提醒

三角形内角范围是 (0, π)，不包括 0 和 π；钝角范围是 (π/2, π)，不包括直角。

定义域管输入，值域规定主值角

以下角度均用弧度表示。

y = arcsin x

定义域：[−1, 1]
值域：[−π/2, π/2]
严格递增；奇函数；两端可取。

y = arccos x

定义域：[−1, 1]
值域：[0, π]
严格递减；不是奇函数；两端可取。

y = arctan x

定义域：ℝ
值域：(−π/2, π/2)
严格递增；奇函数；渐近线不可取。

不能只看“输入是负数”就套 π − arc。要区分输入的正负、主值角的正负，以及题目允许的角的范围。特别是 arccos(−1/2) = 2π/3 > 0。
