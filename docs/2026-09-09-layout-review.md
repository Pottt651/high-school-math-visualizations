# 课堂布局迭代记录

本轮基于已有八题课件改进显示与交互，数学模型和答案保持原有定义。

## 第一轮：阅读与画图区分

- 第18题左右布局从等宽双图改成上方函数、下方相位轴。
- 补入相位区间外最近的极值；增加图内刻度字号，弱化辅助标题。
- 增加题目、思路、答案栏收展及分段解析折叠；保存布局和顶部导航显示偏好。

## 第二轮：动态重绘与独立审阅

- 实际换题、换小问、改参数发现动态解析会替换标题节点，改为观察解析更新并恢复折叠控件与状态，保留公式排版。
- 独立审阅发现第16题展开关键关系后被旧网格规则挤到下半屏，修复该题行布局并增加真实图形间距断言。
- 独立审阅发现高频相位刻度末端拥挤，保留边界标注时排除相邻抽样文字。

## 第三轮：端点与恢复状态

- 连续模式中，极值恰在开区间端点时明确标为“端点”；函数图和相位轴均使用空心点，且不计入极值个数。
- 收起题目、思路或答案后切回上下布局恢复可读；回到左右布局仍保留当前题的收展选择。
- 检查1280×720、1920×1080及390像素窄屏；检查参数、构型、画图步骤、主题和布局切换。

## 验证方式

`npm run test:layout` 覆盖布局切换、左右列实际位置、顶部隐藏、刷新记忆、函数/相位排列、离散候选与连续参数边界、阅读控件和解析重绘。已有浏览器套件检查真实拖动、空间遮挡、公式、颜色对比、离线资源和逐步画图；模型及构建测试另行覆盖数学不变量和输出隔离。

视觉检查使用离线浏览器渲染截图，并由未参与实现的代理独立审阅。当前应用内浏览器此前拒绝打开本地文件，因此不把应用内预览计作通过。
