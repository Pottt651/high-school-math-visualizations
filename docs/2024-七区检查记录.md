## 教学与视觉迭代

沿用仓库 `math-problem-visualizer` 的约束保持、单一数学状态、完整证明与独立检查原则。题述、思路、读数、答案和推导集中在左栏，右栏给图形；可切换布局、隐藏顶部、放大图形、切换深浅画布和收展解析。

本轮实际修复：普通 JavaScript 字符串吞掉 TeX 反斜杠；长公式超出窄阅读栏；绘图误选到 KaTeX 根号内的 SVG；单图/双图切换后画布未按真实宽度重绘；填充透明度同时削弱几何轮廓；部分默认相机造成点重叠和图偏小；分问按钮切换未重置作图步骤；参数控件未同步给出可读结果。

图形是理解工具，不代替证明：离散最值处理并列端点，有限图窗注明局限，全称命题给完整推导。杨浦 21 的二周期按精确关系显示，近似初值有明确标记；杨浦 17 随高度调整取景范围，避免把高棱锥顶点裁出画布。

## 原卷问题

普陀 16 按原卷印刷公式求得范围 `(-3/2,0]∪[3,9)∪(9,+∞)`，四个选项均遗漏 m>9。m=12 时零点 2/3 与 3/4 是可直接代回原式的反例。题述、答案、推导均明确标注，不擅改原式以迎合选项。该问题经两次独立复算及原 PDF 高分辨率页面核对。

## 实际验证结果

- `npm test` 全套通过：隔离构建测试、原嘉定与宝山课件回归，以及新七区的数学模型与浏览器专项检查。
- `tests/2024-classroom.cjs` 对七区全部 43 题运行 1280×720、1920×1080 检查，操作分问和显示控件，检查公式宽度、画布尺寸、状态保持、控制台错误及外部网络请求，全部通过。
- 七份独立 HTML 分别复制进新建的空临时目录，在断网浏览器中打开并切题，全部通过。无 CDN、远程字体或运行时网络依赖。
- 徐汇、静安、普陀的精确边界和几何条件，黄浦的反射/等长弦/局部趋同，嘉定与金山的空间/圆锥曲线/函数模型，杨浦的焦距/离散最值/指数不等式/递推二周期均有专项断言。部分专项另检查 390×844 窄屏、鼠标旋转、分步作图和滑杆端点。
- 主代理实际查看原卷页面、七区主要题型与关键模式的浏览器截图；跨代理独立复核记录保存在各区 review 文件。最后调整杨浦 17 取景后，重新通过杨浦空间专项、点坐标裁切断言、源码检查和整份杨浦课堂/离线回归。
- 构建的 20 个 HTML 输出做重复构建散列检查，输出一致。原 PDF、临时文件、浏览器截图位于忽略目录，不纳入交付。

本机验证使用项目 Playwright/Chromium。应用内 Browser 曾拒绝本地 URL，本轮未绕过该限制，也不将其记为验收通过；用户可以从文件管理器双击课件检查实际教室浏览器效果。
