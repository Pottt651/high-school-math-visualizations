## 离线使用与验证

根目录每区的“区名2025一模_互动讲题.html”可单独复制。嘉定沿用“嘉定一模_互动讲题.html”。脚本、字体、公式排版、样式与绘图资源内嵌，没有 CDN、远程字体、统计脚本或运行时网络请求。跨卷目录跳转仍需要其他文件；一份课件内部切题、滑块、布局和解析不需要。

验证入口：

- `npm run test:2025`：源码与 TeX、四区数学模型、黄浦/徐汇原有测试、新增题目的关键控制、空间旋转与逐步构图、720p/1080p 课堂布局、单文件隔离断网检查。
- `npm test`：连同原有嘉定、宝山和 2024 七区的整体回归。
- `python build.py`：按登记表生成全部独立 HTML 与目录。

迭代中额外修复了旧公共样式的冲突：分步构图的 flex 规则不再覆盖桌面左右布局的 grid，题述与构造步骤仍在左侧，右图保持完整高度；放大图形与窄屏仍采用原有纵向布局。新增 `tests/classroom-construction-layout.cjs` 遍历 15 份试卷，验证其中有构图步骤的 11 份在 720p/1080p 下的左右位置、图形高度、放大/还原及移动端退化，不改变数学状态。
